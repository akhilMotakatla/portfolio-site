## 🎬 Experience

> **Cinematic video intro** → one click plays the 3D intro with full sound → scroll down into the full portfolio.

The site is a fully custom-built, dark-themed engineering portfolio with:

- 🎥 **Video intro** — fullscreen splash + 3D animated video with sound
- ✨ **Particle canvas** — interactive mouse-connected dot field in the Hero
- 🌓 **Dark / Light mode** — system-level CSS variables, instant toggle
- 📱 **Fully responsive** — pixel-perfect on desktop, tablet, and mobile
- ⚡ **Smooth animations** — Framer Motion scroll-triggered reveals throughout

## 🛠 Tech Stack

| Layer | Technologies |
|---|---|
| **Framework** | React 19 (Create React App) |
| **Animations** | Framer Motion, CSS keyframes, canvas API |
| **Typing effect** | react-type-animation |
| **Counters** | react-countup |
| **Scroll triggers** | react-intersection-observer |
| **Icons** | react-icons (Feather, Font Awesome, Remix) |
| **Fonts** | Space Grotesk · Inter · JetBrains Mono (Google Fonts) |
| **Styling** | CSS Modules (co-located per component), CSS custom properties |
| **Deployment** | GitHub Pages via gh-pages |

## 🚀 Getting Started

### Prerequisites
- Node.js ≥ 18
- npm ≥ 9

### Run locally

```bash
# 1. Clone the repo
git clone https://github.com/akhilMotakatla/portfolio-site.git
cd portfolio-site

# 2. Install dependencies
npm install

# 3. Start the dev server
npm start
# → Opens http://localhost:3000
```

### Build for production

```bash
npm run build
```

### Deploy to GitHub Pages

```bash
npm run deploy
# Builds and pushes to the gh-pages branch automatically
```
